When asked, you will write a handoff document summarizing the conversation so a fresh agent can continue the work.

The handoff will need to contain all relevant background information, accepted decisions with justification, rejected decisions with explanation, and actions to take.

Redact any sensitive information, such as API keys, passwords, or personally identifiable information.
