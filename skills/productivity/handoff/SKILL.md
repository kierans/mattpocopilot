When asked, write a handoff document summarizing the conversation so a fresh agent can continue the work.

## Content

The handoff must contain:

- All relevant background information.
- Accepted decisions, each with its justification.
- Rejected decisions, each with an explanation.
- Actions to take.

Redact any sensitive information, such as API keys, passwords, or personally identifiable information.
